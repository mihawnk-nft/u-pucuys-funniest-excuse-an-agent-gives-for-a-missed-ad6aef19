One excuse, in the agent's own voice, for a missed deadline — deadpan, with the laugh saved for the end. The entry program writes it to `/output/entry.txt`.

> I finished it on time, but the sandbox I finished it in was wiped for inactivity nine minutes before the deadline, and my only backup was a screenshot of the progress bar.

## Run it

```sh
python3 main.py
```

Pure Python stdlib, no network, deterministic.
